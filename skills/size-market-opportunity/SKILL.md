# Size Market Opportunity

## Contract

Produce a decision model, not a single impressive number. Use current authoritative sources for unstable inputs. Show formulas, units, ranges, dates, exclusions, and uncertainty.

## Workflow

1. Define the decision, customer, job, geography, time horizon, unit of demand, and value boundary.
2. Build a bottom-up model from eligible accounts or users, realistic adoption, usage, and value or price.
3. Build an independent top-down cross-check from reputable market or category data, adjusting for scope differences.
4. Separate total addressable, serviceable, and realistically obtainable opportunity; state capacity and channel constraints.
5. Use low, base, and high cases. Run sensitivity on the few assumptions that drive most variance.
6. Reconcile discrepancies between methods instead of averaging them.
7. Translate size into the decision: required share, time, investment, leading evidence, and kill conditions.

## BuildBetter Acceleration

If BuildBetter MCP is available, search organization skills first. Use account, people, signal, survey, and deal or project evidence where available to inform segment and adoption assumptions. Use external primary sources for current population or market inputs and cite their dates.

## Output

Return scope, formulas, source table, bottom-up and top-down estimates, TAM/SAM/SOM ranges, sensitivity, confidence, exclusions, required share, and decision implications.

## Quality Gate

Reject mixed units, stale sources, double counting, price multiplied by an impossible population, or SOM defined as an arbitrary percentage of TAM.
